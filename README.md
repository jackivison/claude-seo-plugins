# SEO workflows for Claude Code

A Claude Code plugin marketplace of SEO workflows, each proven on real client sites.

## Add the marketplace

```
/plugin marketplace add jackivison/claude-seo-plugins
```

## Plugins

| Plugin | What it does |
| --- | --- |
| [yoast-meta-upload](plugins/yoast-meta-upload) | Uploads approved SEO titles and meta descriptions to WordPress Yoast in bulk, exactly as approved, with a dry run, an undo record and a live check of every page. |

Install one with:

```
/plugin install yoast-meta-upload@seo-workflows
```
